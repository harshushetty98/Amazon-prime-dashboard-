## 📊 Amazon Prime Video Dashboard (Power BI)
This project presents an interactive Power BI dashboard built using the Amazon Prime Video dataset. The dashboard provides insights into content distribution, 
ratings, genres, and trends over time.



## 🚀 Overview
1.	The dashboard helps analyze:
2.	Total number of titles available on Prime Video
3.	Distribution of genres and ratings
4.	Country-wise availability of content
5.	Growth of movies and TV shows over the years



## 📌 Key Metrics
1.	🎬 Total Titles: 9.65K
2.	🎭 Total Genres: 519
3.	⭐ Total Ratings Categories: 25
4.	🎥 Total Directors: 5.77K



## 📊 Dashboard Features
1.	🌍 Content by Country
	Interactive world map showing distribution of shows across countries
2.	⭐ Ratings Analysis
	Bar chart displaying number of shows by rating category (13+, 16+, etc.)
3.	🎭 Genre Distribution
	Top genres based on number of shows
4.	🎬 Content Type Split
	Donut chart showing Movies vs TV Shows
5.	📈 Trends Over Time
	Line chart showing growth of content by release year

    
## 🛠️ Tools & Technologies
1.	Power BI
2.	Data Cleaning & Transformation using Power Query
3.	Data Modeling using DAX


## 🎯 Insights
1.	Majority of content on Prime Video consists of Movies (~80%)
2.	Content growth has significantly increased after the year 2000
3.	Drama and Comedy are among the most dominant genres
4.	Content availability varies significantly by country

📊 Amazon Prime Video Dashboard (Power BI)
This project presents an interactive Power BI dashboard built using the Amazon Prime Video dataset. The dashboard provides insights into content distribution, 
ratings, genres, and trends over time.



🚀 Overview
The dashboard helps analyze:

Total number of titles available on Prime Video

Distribution of genres and ratings

Country-wise availability of content

Growth of movies and TV shows over the years



📌 Key Metrics
🎬 Total Titles: 9.65K

🎭 Total Genres: 519

⭐ Total Ratings Categories: 25

🎥 Total Directors: 5.77K



📊 Dashboard Features
🌍 Content by Country
Interactive world map showing distribution of shows across countries
⭐ Ratings Analysis
Bar chart displaying number of shows by rating category (13+, 16+, etc.)
🎭 Genre Distribution
Top genres based on number of shows
🎬 Content Type Split
Donut chart showing Movies vs TV Shows
📈 Trends Over Time
Line chart showing growth of content by release year
🛠️ Tools & Technologies


Power BI
Data Cleaning & Transformation using Power Query
Data Modeling using DAX


🎯 Insights
Majority of content on Prime Video consists of Movies (~80%)
Content growth has significantly increased after the year 2000
Drama and Comedy are among the most dominant genres
Content availability varies significantly by country
